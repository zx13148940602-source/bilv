# 毕旅 · 毕业旅行拼团规划

一个面向 10–30 人熟人团的毕业旅行协作 Demo：把「都行」变成可计算的偏好，把分歧变成可接受的结论，把每一笔钱算清楚。

**在线体验：https://zx13148940602-source.github.io/bilv/**

![毕旅首页](screenshot.png)

## 四个核心流程

| Tab | 你能做什么 |
|---|---|
| 团 | 看定案进度、成员意向、预算分布与系统建议 |
| 定案 | 比较 3 个目的地，排序投票，实时看 Borda 分与共识度 |
| 行程 | 切换 D1–D4，查看主干/支线活动，添加自己的安排 |
| 账本 | 记一笔公共开销，查看人均与「谁转给谁」的净额结算 |

## 产品机制

- **意向卡**：时间窗口、预算区间、目的地标签、强度、必去/不去、参与方式；预算匿名进入聚合。
- **可解释匹配**：三道硬约束 + 五维评分，输出覆盖人数、人均区间、不满足名单与替代建议。
- **排序投票**：Borda 计分、一次否决权、截止锁定、共识度与少数派补偿建议。
- **主干 + 支线**：同一时段 A/B 两条线，各玩各的但不散团。
- **分摊引擎**：六种规则、净额结算、贪心压缩转账次数。

## 设计系统

- 视觉：Swiss 极简 + 旅行橙 `#C2410C` + 地图青 `#0F766E` + 纸感底 `#FBF7F2`
- 字体：系统中文字体，15px 正文 / 34px 主标题，数字等宽
- 无障碍：44px+ 触控目标、4.5:1 对比度、可见焦点、弹层焦点陷阱、`aria-live`
- 动效：150–250ms，支持 `prefers-reduced-motion`
- 审查记录：[UI-REVIEW.md](UI-REVIEW.md)
